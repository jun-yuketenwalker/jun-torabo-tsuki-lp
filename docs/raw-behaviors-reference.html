RAWタブ ビヘイビア・リファレンス

キーマップエディタのピッカーで「RAW」タブに直接タイプできる ZMK ビヘイビア(& で始まるトークン)を、実際にこのリポジトリがビルドで使う ZMK v0.3 タグのソース(app/dts/behaviors/)から突き合わせて一覧にしました。

修飾キー記法 — MOD(KEYCODE)

&kp のキーコードは、8種類の「修飾キーで包む」関数でラップすると、その修飾キーを押しながら同時押しした状態を1つのトークンとして送れます。ネストして複数重ねることも可能です。

LS()左Shift
RS()右Shift
LC()左Ctrl
RC()右Ctrl
LA()左Alt
RA()右Alt
LG()左GUI(Win/⌘)
RG()右GUI
&kp LG(TAB)
Win+Tab — タスクビュー切替
&kp LG(D)
Win+D — デスクトップ表示
&kp LG(E)
Win+E — エクスプローラー
&kp LA(F4)
Alt+F4 — ウィンドウを閉じる
&kp LC(LS(ESC))
Ctrl+Shift+Esc — タスクマネージャー
&kp LC(LA(DEL))
Ctrl+Alt+Delete
&kp LC(Z)
Ctrl+Z — 元に戻す
&kp LC(LS(N))
Ctrl+Shift+N — 例: 新規シークレットウィンドウ

01 キー入力・マウス

単発のキーコードや、マウスのボタン・移動・スクロールを送る基本ビヘイビア。

トークン名称引数説明使用例
&kp Key Press 1 通常のキー送信。上の修飾キー記法と組み合わせ可能。 &kp A&kp LG(TAB)
&mkp Mouse Key Press 1 マウスボタン(左/右/中/戻る/進む)を押す。 &mkp LCLK&mkp MB4
&mmv Mouse Move 1 押している間、マウスカーソルを指定方向へ(徐々に加速しながら)動かす。 &mmv MOVE_UP
&msc Mouse Scroll 1 押している間、指定方向にスクロールする。 &msc SCRL_DOWN

02 レイヤー操作

複数レイヤーの切替・一時有効化。レイヤー番号は state.layers の並び順(0始まり)。

トークン名称引数説明使用例
&mo Momentary Layer 1 押している間だけ指定レイヤーを有効化。離すと戻る。 &mo 3
&lt Layer-Tap 2 タップで通常キー、長押し(既定200ms)でレイヤー。 &lt 3 X
&to To Layer 1 指定レイヤーへジャンプし、他の有効レイヤーは解除。 &to 0
&tog Toggle Layer 1 指定レイヤーのON/OFFを押すたびに切替。 &tog 5
&sk Sticky Key 1 次の1回のキー入力にだけ効くワンショット修飾キー(既定1000ms以内)。 &sk LSHIFT
&sl Sticky Layer 1 次の1回のキー入力にだけ効くワンショットレイヤー。 &sl 2

03 ホールドタップ

同じキーでも「短押し」と「長押し」で違う動作をさせる系。

トークン名称引数説明使用例
&mt Mod-Tap 2 タップで通常キー、長押しで修飾キー(いわゆるホームロー修飾)。 &mt LSHIFT F
&gresc Grave/Escape 0 通常はEsc、Shift/GUIを押しながらだと `(バッククォート)。 &gresc

04 単発ユーティリティ

状態を持つ・特殊な単発挙動をするキー。

トークン名称引数説明使用例
&trans Transparent 0 下のレイヤーの割り当てをそのまま透過させる(このツールの既定値)。 &trans
&none None 0 何も送信しない(キーを無効化)。 &none
&caps_word Caps Word 0 1回押すと発動、英数字を打っている間だけ自動でShiftがかかり続け、スペースや記号で自動OFF(CapsLockと違い消し忘れない)。 &caps_word
&key_repeat Key Repeat 0 直前に押したキーをもう一度送信する。 &key_repeat
&kt Key Toggle 1 押すたびに「押しっぱなし状態」をON/OFFする(通常のタップ動作とは別枠)。 &kt LCTRL

05 Bluetooth / 出力切替

ピッカーの BLUETOOTH タブに無い細かい操作は、こちらを直接タイプ。

トークン名称引数説明使用例
&bt Bluetooth 2 プロファイルの選択・削除・切替。BT_SEL=選択、BT_CLR=現プロファイル削除、BT_CLR_ALL=全削除、BT_NXT/BT_PRV=前後移動、BT_DISC=切断。 &bt BT_SEL 0&bt BT_NXT
&out Output Selection 1 USB/BLEどちらに出力するかの切替。OUT_TOG=トグル、OUT_USB/OUT_BLE=固定。 &out OUT_TOG

06 システム / 電源

再起動・書き込みモード・省電力まわり。

トークン名称引数説明使用例
&sys_reset Reset 0 マイコンをソフトリセット(再起動)する。 &sys_reset
&bootloader Bootloader 0 UF2書き込み用ブートローダーモードに入る(本体ボタン操作なしでファーム更新できる)。 &bootloader
&soft_off Soft Off 0 電源を落として消費電力を抑える。分割キーボードの子機側は次回接続時に自動復帰。 &soft_off
&ext_power External Power 1 外部電源ライン(LED等への給電)のON/OFF/トグル。 &ext_power EP_TOG
対応する電源回路が実機に無い場合は無効

07 ライティング

実機にLED配線があって初めて意味を持つ系。torabo-tsuki-lpのXS構成に搭載されているかは要確認。

トークン名称引数説明使用例
&rgb_ug Underglow 2 RGBアンダーグロウLEDのON/OFF・色相・明度などを操作。 &rgb_ug RGB_TOG
要アンダーグロウLED配線
&bl Backlight 2 単色バックライトの明るさ調整。 &bl BL_TOG
要バックライトLED配線

08 その他・このボードでは非対応の可能性

存在はするが、torabo-tsuki-lpの標準構成では対応するハードウェアが無い可能性が高いもの。

トークン名称引数説明使用例
&enc_key_press Sensor Rotate 2 ロータリーエンコーダーの回転をキー入力に変換。 &enc_key_press
要ロータリーエンコーダー搭載
&studio_unlock Studio Unlock 0 ZMK Studioでの設定書き込みロックを解除する専用キー。以前検討したDYA Studio等でも使用。 &studio_unlock

09 マクロ内部トークン(参考)

マクロ定義そのものの中で、後続のステップの挙動を切り替えるための制御用トークン。通常はマクロタブが自動生成するため、RAWで手打ちする場面は少ない。

トークン役割説明
&macro_tapタップモード以降のステップを「押して即離す」動作にする(既定)。
&macro_press押しっぱなしモード以降のキーを押しっぱなしにする(&macro_releaseまで保持)。
&macro_release解放モード押しっぱなしにしていたキーを離す。
&macro_tap_timeタップ時間設定以降のタップの押下時間(ms)を指定。
&macro_wait_time待機時間設定以降のステップ間の待ち時間(ms)を指定。
&macro_pause_for_releaseキーを離すまで待機マクロを起動したキー自体を離すまで、実行を一時停止する。
